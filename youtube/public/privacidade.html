Política de Privacidade

A sua privacidade é importante para nós. Esta política explica como o SaveTube lida com informações dos usuários.

1. Dados que coletamos

  • Endereço IP: usado apenas para controlar o limite de 3 downloads grátis por dia.
  • Links do YouTube: processados temporariamente para gerar o download. Não armazenamos o histórico de links.
  • Saldo de créditos: armazenado no navegador do usuário (localStorage), não em nossos servidores.

2. Como usamos os dados

Os dados são utilizados exclusivamente para operação do serviço: processar downloads, gerenciar vouchers e limitar abusos. Não vendemos dados a terceiros.

3. Cookies e armazenamento local

Usamos o localStorage do navegador para guardar o saldo de créditos e o voucher resgatado. Não utilizamos cookies de rastreamento ou publicidade.

4. Segurança

Adotamos práticas razoáveis de segurança, mas não podemos garantir proteção absoluta contra acessos não autorizados. Não armazenamos dados bancários ou senhas dos usuários.

5. Direitos do usuário

Você pode limpar o localStorage do navegador a qualquer momento para remover seus dados locais. Para dúvidas, entre em contato pelo WhatsApp disponível na página de pagamento.

6. Alterações

Esta política pode ser atualizada periodicamente. Recomendamos consultá-la antes de usar o serviço.
